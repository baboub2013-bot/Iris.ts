# Contributing to ProfileSpoofer

Thanks for your interest in ProfileSpoofer.

The project is currently experimental and Discord internals can change frequently.

## Before submitting a change

Please:

- Build the latest version successfully
- Test on a supported Discord client
- Avoid introducing hardcoded secrets
- Keep spoofing client-side
- Preserve existing privacy controls
- Avoid patches broader than necessary
- Document new network behavior

## Bug reports

Include:

- Discord client channel
- Vencord version
- ProfileSpoofer version or commit
- Reproduction steps
- Relevant logs

Never post account tokens, cookies or private credentials.
