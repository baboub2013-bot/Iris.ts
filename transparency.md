# Transparency

This document explains how AI has been used during the development and documentation of **Iris.ts**.

I believe in being transparent about the tools I use, including AI.

## 1. Documentation

AI assistance was used to write, structure, and improve **all README files** in this project.

This includes:
- Writing and improving explanations.
- Organizing features and installation instructions.
- Fixing grammar and improving readability.
- Formatting documentation using Markdown.

## 2. Debugging & Troubleshooting

AI was also used to assist with debugging and troubleshooting.

Discord's internal systems can be complicated to work with, especially when trying to locally customize or spoof profile elements through Vencord.

AI helped with:
- Understanding errors and unexpected behavior.
- Investigating Discord's internal structures and limitations.
- Identifying potential causes of broken features.
- Suggesting fixes and alternative approaches.
- Troubleshooting compatibility issues.

AI assistance does not guarantee that every suggested solution works. Changes still need to be reviewed and tested.

## 3. Development & Responsibility

AI was used as a development assistant, particularly for documentation and debugging.

Its use does not mean the entire project was automatically generated by AI.

I remain responsible for the project, its maintenance, and the code I publish.

## 4. Future Disclosures

When AI is used to generate or significantly modify source code, I aim to document that assistance in a comment at the beginning of the affected file, including its purpose.

This document may be updated as the project evolves.
