# Security Policy

Iris.ts is experimental software.

## Sensitive information

Never include any of the following in bug reports, issues, screenshots or logs:

- Discord account tokens
- Discord cookies
- OAuth session tokens
- Cloudflare secrets
- Discord application client secrets
- Passwords
- Private API credentials

## Reporting a security issue

If you discover a vulnerability that could expose user credentials or private data, do not publish sensitive reproduction data in a public GitHub issue.

Provide only the minimum information necessary until a private reporting method is available.
